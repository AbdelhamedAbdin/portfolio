# KyroStack static website

Upload the contents of this folder to a GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, the main branch, and the root folder. The site needs no build step or backend.

Before publishing, set `WHATSAPP_NUMBER` in `script.js` to your real business number in international format without `+`, spaces, or punctuation. Until then, the WhatsApp button opens a general WhatsApp message without a recipient. Confirm the email, street address, reviews, and project claims copied from the reference screenshots before publishing. The Karenode project card uses the supplied logo and cover and is marked Completed. Confirm the public karenode.com destination before publishing: it could not be reached during preparation.

A custom domain for KyroStack and the `karenode.kyrostack.com` subdomain need separate GitHub Pages/DNS configuration. No DNS or repository settings are changed by these files.
